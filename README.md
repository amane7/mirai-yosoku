# Future Nexus OS

> **未来は、点ではなくネットワークでできている。**

未来を構成する因子（技術・データ・組織・文化・人材・規制・市場・リスク）を **時系列の因果ネットワーク** として構造化し、
**中心媒介性・影響度・反実仮想シミュレーション** によって「未来の急所」と「介入点」を発見する意思決定支援 OS。

単なる未来予測アプリではなく、**未来を編集可能な因果ネットワークとして扱い、現在の打ち手へ落とし込む**ためのツールです。

---

## ✨ 実装済みの機能（8画面）

| 画面 | 内容 |
| --- | --- |
| **Overview** | ヒーロー・KPI・急所Top5・機能ナビの統合ダッシュボード |
| **Future Map** | Cytoscape による因果ネットワーク。ノード径＝指標、線＝影響度、クリックで近傍ハイライト、カテゴリフィルタ、指標切替（媒介性/FCS/KO影響） |
| **Sankey Timeline** | 現在→未来への因果フロー。ピーク年でレイヤー分け、指標切替、トポロジカル整列による DAG 化 |
| **Criticality Ranking** | 6スコアの多面評価テーブル（列クリックで並替）＋ Future Criticality Score の式表示 |
| **Knockout Simulator** | 因子を弱める／遅らせる反実仮想。差分バーチャート・低下率・遅延年数・影響経路を自動算出。プリセット操作付き |
| **Backcasting Planner** | 望ましい未来から逆算するロードマップ・タイムライン |
| **Causal Loops** | 好循環(R)／抑制ループ(B)を SVG リングで可視化 |
| **Executive Report** | 重要因子・示唆・推奨打ち手・監視リスクを自動構造化した経営層向け1枚サマリー |

### 分析エンジン（純TypeScript・NetworkX相当）
- **中心媒介性**: Brandes アルゴリズム
- **影響伝播**: 活性化拡散（減衰付き、抑制エッジ対応）
- **ノックアウト影響度**: 各因子を0にした全体活性度の低下率
- **ボトルネック度 / 直接・間接影響度**
- **Future Criticality Score** = 媒介性 × 影響度 × 時間重要度 × KO影響 × 証拠強度 ÷ 代替可能性

## 📌 設計思想（リスク対策）
- 「予測」ではなく「シナリオ」。不確実性・信頼度・根拠を必ず表示
- スコアは絶対値ではなく **比較指標 / 議論の入口**
- AI提案（仮説）と人間レビュー済みを区別（破線＝未レビュー）
- 生成AIは「予測する役」ではなく「構造化支援者」
